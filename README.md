# 延世韩国语 · 单词背诵面板

> 📖 在线使用：打开本仓库的 GitHub Pages 首页（`https://<用户名>.github.io/<仓库名>/`）

延世韩国语 1–6 册单词背诵工具，共 **4160 条**单词（含词组与关键句型，全书去重）。

## 功能

- 六册总览与切换，按课分组（每课：序号｜韩文｜中文｜打卡）
- 点击打卡 ✓，进度条实时统计
- 🎴 自测模式：遮住中文，点击临时显示
- 韩文/中文即时搜索
- 👤 多用户：右上角改名字，各人进度互不干扰
- 🖨 页脚有六册打印版背诵本（book1.html ~ book6.html），可打印成纸质册

## 说明

- 单词内容为自编学习课件的词汇表（跟随延世韩国语教学进度自编，非课本原文）
- 网页版（GitHub Pages）的打卡进度保存在各自浏览器本地（localStorage）
- 浏览量统计由[不蒜子](https://busuanzi.ibruce.info/)提供，显示在页脚

仅供个人学习使用。
